# Lazurite Leap

Full-colour Python 3 neon frogger-style tide hopper arcade for ElbowOS.

Hop a neon frog across moving platforms, collect gold gems, avoid hazards.

## Play
```
pip install -r requirements.txt
python3 lazurite_leap.py --play
```
Controls: A/D or arrows move, Space hop, R restart.

## Record 9:16 reel
```
python3 lazurite_leap.py --record
```
Outputs LAZURITE_LEAP_ElbowOS.mp4 (1080x1920, 15s @30fps).
